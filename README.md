# Тестовое задание «teaboom»

Тестовое задание выполнено в соответствии с техническим заданием. Реализована интерактивная карточка товара «Ананасовый улун» с основными функциями для выбора и добавления товара в корзину.

## Что реализовано

- Отображение информации о товаре, фотографий и характеристик.
- Выбор фасовки с автоматическим обновлением цены и артикула.
- Управление количеством товара с помощью кнопок.
- Автоматический расчёт итоговой стоимости с учётом количества.
- Увеличение фотографии товара для более детального просмотра.
- Добавление товара в корзину с уведомлением о результате действия.
- Адаптация интерфейса под разные размеры экрана.

## Технологии

- HTML5
- CSS3
- JavaScript (Vanilla JS)

Проект реализован без сторонних библиотек и фреймворков.
